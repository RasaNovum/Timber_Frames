<p align="center"><img src="https://i.imgur.com/XTdgaJB.png" alt="FAQ" width="1200" /></p>

### Is 3.X compatible with 1.X &amp; 2.X world saves?

- No, Timber Frames has been re-written from the ground up allowing for much more creativity.

### Will this mod be available for version X?

- <img src="https://i.imgur.com/jLQd2vq.png" alt="I don't know" width="310" />

### Can I use Optifine?

- Maybe, but I would advise against it.

### Are there any modded wood variants?

- Yes! All modded wood types should automatically have Timber Frame blocks in-game, if they don't please leave an issue on GitHub so we can look into it.

### Can I use this in my modpack and/or server?

- Yes, as long as it's downloaded from our official sources.

### What is Rasa Novum?

- We're a small group of friends making mods for our modpack and eventual server.
