# Timber Frames 3.0.0 Changelog:

### Features:
- Rebuilt Timber Frames from the ground up allowing for much more possibilities.
- Dynamic Timber Frame variants generated from vanilla and common wood tags.
- Data-driven recipe groups for automatically supporting Timber Frame block families.
- Broad Knife tool for drawing and removing structural lines.
- Grid-snapped Broad Knife placement with live client-side previews.
- F3 debug visualization for timber frame raster groups.
- 1.20.1/1.21.1 Fabric, Forge, and NeoForge support.
 
### Important Notes:

- This release is not compatible with blocks from the legacy Timber Frames releases.
- Legacy barn-related blocks and the isolation variant are not included (but will be added in the future in the form of a datapack).
